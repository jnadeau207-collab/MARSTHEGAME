# ADR 0022: Project-generated character and audio content

- Status: Implemented candidate
- Date: 2026-07-27

## Decision

The representative Ares Reach slice uses a project-generated articulated character assembled from native procedural geometry and driven by a deterministic locomotion pose generator. The authored player scene entity remains the gameplay and collision authority; supplemental rig parts are presentation-only and do not alter save, replay, objective, or collision semantics.

The slice also uses deterministic project-synthesized stereo audio generated by native code. No prerecorded commercial music, external sound library, imported character, external rig, or animation marketplace dependency is introduced.

## Verification

Character-pose and audio-content determinism, finite-value validation, state divergence, amplitude safety, and seed divergence are covered by strict native tests. Runtime integration remains subject to the Phase 5 executable and founder approval gates.
