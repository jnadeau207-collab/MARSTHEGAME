# MARSTHEGAME Native Runtime

This directory contains the complete product runtime.

- `src/game` — deterministic gameplay and mission state
- `src/platform` — Win32 window and message ownership
- `src/renderer` — Direct3D 12 renderer and scene contracts
- `shaders` — HLSL compiled by DXC
- `tests` — strict native C++ tests

Build and test from an x64 MSVC developer shell using the commands in the repository README.
